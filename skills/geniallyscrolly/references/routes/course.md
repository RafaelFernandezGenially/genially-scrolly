# Route: course

For learning modules, onboarding, compliance and skills training. Read `../learning-design.md` first.

**Skeleton (12–16 beats):** start (title, time to complete, progress tracker) → objectives (words + glossary) → teach in steps (steps with diagrams; deep-zoom for detail) → a video with a question (video-quiz) → check (quiz) → apply (scenario) → practise (flashcards, sort) → finish (certificate).

**Blocks that fit:** progress, words, glossary, steps, deep-zoom, hotspots, compare, video-quiz, quiz, scenario, flashcards, sort, certificate, timeline.

**Traps:** at least one activity per 2–3 teaching beats; every quiz explanation teaches (no bare "Wrong"). Keep motion calm: learners need to read. Progress is saved per device only; LMS/xAPI reporting is an Enterprise feature (not live).
