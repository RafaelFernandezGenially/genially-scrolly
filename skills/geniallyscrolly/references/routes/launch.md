# Route: launch

For product launches, feature announcements, campaigns.

**Skeleton (8–10 beats):** particles or video-scrub opener → title → portal into "what's new" → feature stack (3 cards) → details sideways (horizontal) → before/after (compare) → proof (kpi) → call to action (magnetic).

**Blocks that fit:** particles, video-scrub, sequence, reveal, portal, stack, horizontal, compare, spotlight, kpi, magnetic, grow.

**Traps:** launch pages are usually commercial → tell the user about the licence (step 7). Hero motion is fine, but keep the call to action reachable within 3 screens on phones.
