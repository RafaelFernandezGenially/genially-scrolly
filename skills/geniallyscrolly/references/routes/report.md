# Route: report

For data stories, annual reports, research summaries. Read `../data-viz.md` first.

**Skeleton (8–12 beats):** headline finding (reveal + marker) → at a glance (kpi) → the main trend (chart line) → comparison (chart bar) → who leads over time (chart race, pinned) → composition explained in steps (steps with waffle/donut) → one big number (counter, pinned) → findings (color-flow) → sources.

**Blocks that fit:** kpi, chart (bar, line, donut, waffle, race), steps, counter, marker, color-flow, reveal. More forms with the same `chart` block: treemap, sunburst, slope, dumbbell, waterfall, radial, multiples, annotated (pinned), network, heatmap, beeswarm, ridgeline, radar, gantt, morph, globe, map-flight (see `data-viz.md`). Also `gauge`, `pictogram`, `scatter` inside `steps`, `waffle-steps`, `odometer`, and one `bars3d` for a hero moment.

**Traps:** never invent numbers and present them as real; label sample data. One message per chart, written as the chart title.
