# Pro features & licensing (what to tell the user)

Genially Scrolly is open source under the **Genially Scrolly License**: free for non-commercial use; commercial use needs a paid licence (similar in spirit to Remotion's model). The **"Made with Genially Scrolly" mark** is part of the free tier.

| | Free | Creator | Team | Enterprise |
|---|---|---|---|---|
| Non-commercial use | ✓ | ✓ | ✓ | ✓ |
| Commercial use | — | 1 person | organisation | organisation |
| All blocks, templates, CLI, skills | ✓ | ✓ | ✓ | ✓ |
| Remove the mark | — | ✓ | ✓ | ✓ |
| Genially analytics (scroll depth, completions, quiz results) | — | ✓ | ✓ | ✓ |
| Genially APIs: AI images in your style, asset library, publish to Genially | — | — | ✓ | ✓ |
| LMS / xAPI reporting, SSO, custom terms | — | — | — | ✓ |

**The Genially connection is hypothetical in this release.** The runtime already has the hooks (`Scrolly.init({license})`, `Scrolly.pro.verify`, `Scrolly.track`, `Scrolly.genially.*`) but no live endpoint, so every key resolves to "not connected": the mark stays and Pro calls reject with `pro_required`.

## Wording for the user (adapt, keep it short)

- Non-commercial: "It's free for non-commercial use; the small 'Made with Genially Scrolly' mark stays on."
- Commercial or unsure: "For commercial use (a company, a client, a paid course) you'll need a Genially Scrolly licence. That also removes the mark."
- They ask for AI images / analytics / no mark: "That's a Pro feature: it needs a licence and a connection to Genially, which isn't available yet. For now I've used [free alternative]. When it opens, you'll activate it with `npx genially-scrolly license activate <key>` and nothing else in the page changes."

## Never

- Hide, remove, cover or restyle away the mark (CSS or JS) without a verified licence.
- Pretend a key was verified, an image was generated by Genially, or analytics are recording.
- Put keys or tokens in public pages beyond the licence key field the runtime expects.
