# Learning design (L&D)

Scrollytelling suits learning because it paces content and keeps the diagram on screen while the explanation moves. Use activities with purpose:

| Need | Block | Rule of thumb |
|---|---|---|
| Show the path and let people come back | progress | Top of the page; it lists every activity automatically |
| Check understanding | quiz | 2–4 questions per chapter; every answer has an explanation |
| Practise a decision or conversation | scenario | 3–5 nodes, at least one good, one partial and one bad ending |
| Memorise terms | flashcards | 5–12 cards; missed cards return sooner |
| Practise judgement | sort | 6–10 items, 2–3 boxes |
| Help newcomers without slowing experts | glossary | Define on first use |
| Keep video active | video-quiz | One question at the key moment |
| Close and record | certificate | Last section; free tier prints the Genially Scrolly mark |

- Progress is stored on the learner's device (localStorage) and is not sent anywhere in the free tier.
- Reporting results to an LMS (SCORM/xAPI) or to Genially analytics is a Pro/Enterprise feature that needs the Genially connection (not live in this release).
- Write feedback that teaches: "Not quite. X happens because Y."
- Keep motion calm in courses; the reader must be able to stop and read.
