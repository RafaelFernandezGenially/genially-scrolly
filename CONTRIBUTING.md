# Contributing

1. Fork, then `npm run build` and open `examples/kitchen-sink` with `npx genially-scrolly preview examples/kitchen-sink`.
2. New block: see `skills/geniallyscrolly-blocks/SKILL.md`.
3. Every block must work in calm mode (reduced motion), on a 390 px phone and with the keyboard.
4. Run `npm run lint:example` and `npm run verify`; attach desktop and phone screenshots to your PR.
5. By contributing you accept section 4 of LICENSE.md.
