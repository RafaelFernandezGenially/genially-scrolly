By hand

The CLI scaffolds, checks and builds.

npx genially-scrolly init my-story \
  --template story --theme editorial
cd my-story
npx genially-scrolly preview
npx genially-scrolly lint
npx genially-scrolly verify   # desktop + phone
npx genially-scrolly build

Published.

Interview, once. Up to four questions: goal, route, style, content. The answers become BRIEF.md.

Storyboard. One idea per beat, a block per beat, a pin budget and real-or-sample data labels.

Build. A template in your style, filled with your copy. Every effect is a data-scrolly block.

Check. Lint for structure, accessibility and licence rules; screenshots on desktop and phone; calm mode.

Ship. One Artifact inside claude.ai, or a static folder for any host.
